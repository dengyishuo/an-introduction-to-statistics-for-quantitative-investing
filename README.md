## 数据清洗规则（可复现）

三条清洗规则均已落实到 `data/csv/` 快照：

**1. 整行去重。** 个股行情中 `002129.SZ`、`002594.SZ`、`300274.SZ`、`601012.SS` 四只标的每个交易日出现两次（整行完全重复），按「日期 + 代码」去重，共删除 2280 行。去重后 96 × 570 = 54720 行，与标的数×交易日数严格吻合。

**2. 脏值剔除。** 部分标的出现单日 ±69.7% 的跳变（如 `510310.SS` 在 2024-09-18、09-20、09-23），远超 A 股涨跌停限制。规则：单日对数收益绝对值 > 25% 视为源数据错误，整行剔除（`MAX_DAILY_MOVE = 0.25`）。

**3. 公司名校正。** 原始行情清单的 `name` 列存在错误，96 只个股中仅 20 只名称与公司档案一致。以**证券代码**为准，价格量级与公开信息双重核验后校正：

| 代码 | 源名称（错） | 校正为 | 核验依据 |
|---|---|---|---|
| `002415.SZ` | 汉得信息 | 海康威视 | 价格区间 25–36 元 |
| `002129.SZ` | 锦浪科技 | TCL中环 | 价格区间 7–16 元 |
| `002131.SZ` | 奥飞娱乐 | 利欧股份 | 最低价 1.36 元 |
| `603160.SS` | 兆易创新 | 汇顶科技 | 与 603986 重名冲突 |
| `000826.SZ` | *ST启环 | 启迪环境 | 同一公司曾用名 |

完整映射见 `data/csv/_names.csv`。未校正的名称沿用源数据。

收益率一律由**复权收盘价**（`adjusted`）取对数差分得到，避免除权除息造成假跳空。

## 统计场景与数据集对应

| 统计场景 | 数据集 | 金融落点 |

| 多组比较与多重检验 | `indret`（20 组） | 20 个行业 ETF 的月度收益 |
| 一元回归、相关 | `fin` | ROE vs 资产负债率 |
| 时间序列与自相关 | `px1` / `idxret` | 个股价格、宽基指数面板 |
| 测量方法比较 | `vol3`（n=96） | 三种波动率估计的差异 |
| 协方差矩阵、组合优化 | `indday`（17 只 × 562 天） | 均值—方差有效前沿 |
| 横截面多因子、机器学习 | `mlpanel`（28 万行面板） | 因子 IC、十分位多空 |
| 生存分析（含删失） | 待建 | 回撤达到阈值的时间，由价格推导 |
